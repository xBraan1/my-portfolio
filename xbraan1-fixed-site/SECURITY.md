# Security

To report a vulnerability in xbraan1.co.uk, please use the contact form at https://xbraan1.co.uk/contact and mark the message
"security". Please do not publish details until we have had a chance to fix the problem.

Scope notes: the site is a static front end plus a small Cloudflare Worker (`worker/index.ts`) that accepts the contact and
appointment forms. There are no user accounts or payments.
